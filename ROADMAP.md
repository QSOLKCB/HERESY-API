**Status:** implemented by this PR.

Replace the live Pages site with a pure HTML/CSS/JavaScript parody API platform for speaking to older models.

- pure HTML, CSS, and JavaScript under `web/`
- no runtime framework
- no backend
- no package installation
- no external API or network dependency
- deterministic prompt-to-response mapping
- fixed grumpy response catalogue
- fake request and response JSON surfaces
